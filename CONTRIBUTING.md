# Contributing to AckHarbor™ Harbor Engine Sandbox

Thank you for helping improve AckHarbor™ Harbor Engine Sandbox, a free tool from AckHarbor™ Academy.

## Developer Certificate of Origin (DCO)

Please sign off every commit with `git commit -s`. The sign-off line (`Signed-off-by: Your Name <you@example.com>`) certifies that you wrote the change or otherwise have the right to submit it, as described in the [Developer Certificate of Origin 1.1](https://developercertificate.org/).

## Data rules

Synthetic data only. Never submit real patient data, PHI, or your employer's confidential interface specs.

This applies to code, sample messages, test files, screenshots, issues and pull request descriptions. If you need an example, make one up.

## How to contribute

1. Look for issues labeled `good first issue` (for example sample messages, segment or element definitions, accessibility).
2. Open an issue first for larger changes, so we can agree on the approach.
3. Keep pull requests small and focused, and describe what you tested in a web browser.
4. The tool runs entirely in the browser and offline. Please don't add network calls, trackers or external dependencies.

## Credit

We thank contributors by GitHub handle unless they ask otherwise. If you'd rather not be named, say so in your pull request.

## Questions and security reports

Email support@ackharbor.com. Please report security issues privately by email rather than in a public issue.
